# Фитнес-дневник (Fitness)

Android-приложение для ведения дневника тренировок: отслеживание упражнений, подходов, весов и прогресса.

## Возможности

- **Тренировки** — создание и ведение тренировок с упражнениями, подходами, весами и количеством повторений
- **Круговые тренировки** — режим круговых тренировок: составление круга из упражнений, кольца, таймер отдыха между кругами, изменение порядка упражнений перетаскиванием
- **Таймеры с паузой** — время подхода и отдыха с возможностью поставить на паузу; подсветка при превышении лимита отдыха
- **Пульсометр (BLE)** — подключение BLE-нагрудного пульсометра H808S (COOSPO), отображение текущего пульса и запись показаний во время тренировки
- **Библиотека упражнений** — каталог упражнений с группировкой по мышечным группам и категориям
- **История** — просмотр завершённых тренировок с деталями (длительность, объём, количество подходов и упражнений) и графиками пульса (по тренировке, подходам и кругам); для круговых — переключение «По кругам / По упражнениям»
- **Сохранение и возобновление** — незавершённая тренировка сохраняется (включая таймеры и показания пульса), её можно продолжить позже с того же места
- **Прогресс** — график прогресса рабочего веса по выбранному упражнению, максимальный вес и расчёт 1ПМ (по формуле Эпли)
- **Настройки** — настройка времени отдыха между подходами по умолчанию (по умолчанию 240 с)
- **Экспорт данных** — выгрузка всех данных (включая показания пульса) в JSON-файл (в папку Downloads)

## Технологии

- **Язык:** Kotlin
- **UI:** Jetpack Compose (Material 3, material-icons-extended)
- **Навигация:** Navigation Compose
- **База данных:** Room (SQLite) с миграциями
- **Архитектура:** MVVM (ViewModel + Repository + Flow)
- **BLE:** Bluetooth Low Energy — стандартный сервис Heart Rate (0x180D)
- **Сборка:** Gradle 8.13 (Kotlin DSL), KSP 2.1.0-1.0.29

## Модель данных

- **Exercise** — упражнение (название, мышечная группа, категория)
- **Workout** — тренировка (время начала/окончания, заметки, признак круговой, JSON незавершённой сессии, время паузы)
- **WorkoutExercise** — упражнение в рамках тренировки (порядок)
- **SetEntry** — подход (вес, повторения, время отдыха, длительность, время начала/окончания, средний и максимальный пульс)
- **HeartRateSample** — показание пульса (workoutId, timestamp, bpm)

## Разрешения

Приложению требуются следующие разрешения для работы с BLE-пульсометром:
- Android 12+ (API 31+): `BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`
- Android 11 и ниже: `ACCESS_FINE_LOCATION`
- Устройство должно поддерживать Bluetooth LE

## Требования

- Android 8.0 (API 26) и выше
- JDK 17
- Android SDK 36 (targetSdk 35)
- Gradle 8.13

## Сборка

```bash
./gradlew assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/`.
